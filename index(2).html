牙龈炎 vs 牙周炎 区别

🟢 牙龈炎（可逆）

仅牙龈红肿出血，未伤及深层组织。通过洗牙和正确刷牙可完全恢复。

🔴 牙周炎（不可逆）

已破坏牙槽骨和牙周膜，形成牙周袋。只能控制，无法完全治愈。

关键区别：牙龈炎不松动，牙周炎牙齿会松动！

7天护牙养成计划

科学习惯，从这一周开始

1

基础检查日

了解自己的口腔现状

✓ 对着镜子检查牙龈颜色（健康：粉红色，发炎：深红/紫红）

✓ 记录是否有刷牙出血情况

✓ 购买软毛牙刷和含氟牙膏

2

正确刷牙法

学习巴氏刷牙法

✓ 牙刷45度角对准牙龈沟

✓ 小幅度水平颤动（2-3颗牙为一组）

✓ 每次刷牙至少2分钟，每天2次

✓ 观看教学视频纠正手法

3

牙线初体验

清洁牙缝，去除邻面菌斑

✓ 购买牙线棒或卷状牙线

✓ 学习C字形包绕牙面上下刮擦

✓ 每晚睡前使用一次

✓ 出血是正常的，坚持一周会改善

4

饮食调整日

减少糖分摄入

✓ 用白开水代替含糖饮料

✓ 吃完零食后漱口

✓ 增加蔬菜水果摄入（纤维清洁牙齿）

✓ 避免睡前吃东西

5

漱口水使用

辅助清洁，抑制细菌

✓ 购买含氯己定或精油的漱口水（非必需）

✓ 刷牙后使用，含漱30秒

✓ 不要立即用清水漱口（保持药效）

✓ 注意：漱口水不能替代刷牙

6

习惯巩固日

建立完整口腔护理流程

✓ 早：刷牙2分钟

✓ 中：午饭后漱口

✓ 晚：刷牙2分钟 + 牙线 + 漱口水

✓ 设置手机提醒，坚持21天养成习惯

7

专业检查预约

定期洗牙，专业防护

✓ 搜索附近口腔医院/诊所

✓ 预约洗牙（龈上洁治）

✓ 咨询医生是否需要深度清洁

✓ 建立每年1-2次洗牙的习惯
